# 유콜 보드 (Android) — 잘 안 되는 전자칠판용 호환판

📣 유콜(YOUcall) — 교무실에서 학생을 부르면 교실 전자칠판에 뜨는 호출 시스템의 **안드로이드 전자칠판용 앱**입니다.

> ⚠️ **이 저장소는 「기본판이 잘 안 되는 칠판」 전용입니다.**
> 먼저 [기본판(youcall-board)](https://github.com/kimju1416/youcall-board/releases/latest)을 써 보시고,
> **막힐 때만** 이 호환판을 쓰세요. 화면과 기능은 완전히 같습니다.

## 이럴 때 쓰세요

**① 설정이 안 넘어갈 때 (가장 흔합니다)**

- 반까지 입력했는데 **[저장하고 시작하기] 버튼을 누를 수 없다** (키보드가 가림)
- 저장을 눌러도 **아무 반응이 없다** / "연결 확인 중..."에서 멈춘다
- 셋 다 채웠는데 **"URL·학년·반을 모두 입력하세요"**만 뜬다

**② 설치 자체가 안 될 때**

- **"구문 분석 오류"** / "패키지를 파싱하는 중 문제가 발생했습니다"
- **"앱이 설치되지 않았습니다"** (출처 허용을 이미 켰는데도)

## 기본판과 무엇이 다른가요?

| | 기본판 | **호환판 (이 저장소)** |
|---|---|---|
| 설정 화면 | 키보드가 저장 버튼을 가림 | **버튼이 따라 올라오고, Enter로도 저장** |
| 주소 입력 | `https://`를 빼먹으면 조용히 멈춤 | **자동으로 붙여줌** |
| 필요한 안드로이드 버전 | 7.0 이상 | **6.0 이상** |
| 앱 서명 방식 | v2 | **v1 + v2** (구형 설치 관리자 대응) |
| 앱 이름 | 유콜 보드 | 유콜 보드 (호환) |
| 그 외 화면·기능 | | **완전히 동일** |

**쓰던 구글 스프레드시트와 웹앱 주소를 그대로 씁니다.** 서버(Apps Script)는 손댈 필요가 없습니다.

> 💡 기본판과 **동시에 설치할 수 있습니다** (앱 이름이 달라 구분됩니다). 호환판이 잘 되면 기본판은 지우세요.
> 💡 **설치는 선택 사항입니다.** 지금처럼 전자칠판 브라우저로 유콜에 접속해서 쓰셔도 모든 기능이 똑같이 동작합니다.
> 💡 전자칠판에 **Windows PC를 연결해서** 쓰신다면 이 앱 대신 [유콜 데스크(Windows용 exe)](https://github.com/kimju1416/youcall-desktop/releases/latest)를 설치하세요.

## 우리 교실은 어느 쪽인가요?

| 전원을 켰을 때 화면 | 쓰실 것 |
|---|---|
| 앱 아이콘들이 있는 화면 (Chrome, File Manager 등) | **이 앱 (유콜 보드 APK)** |
| 윈도우 바탕화면 (아래에 시작 버튼 ⊞) | [유콜 데스크 (exe)](https://github.com/kimju1416/youcall-desktop/releases/latest) |

## STEP 1. 우리 학교 유콜 주소부터 준비하세요 (가장 중요)

1. 전자칠판에서 평소 유콜을 열던 주소를 브라우저로 엽니다 (즐겨찾기에 있을 수 있습니다)
2. 주소창을 길게 눌러 **[복사]**
3. 주소 뒤에 `?role=teacher` 가 붙어 있으면 그 부분은 빼고 `.../exec` 까지만 사용합니다

> ❓ 주소를 모르겠다면 — 교무실 PC에서 유콜 스프레드시트 ▸ **확장 프로그램 ▸ Apps Script ▸ 배포 ▸ 배포 관리**에서 확인할 수 있습니다.

## STEP 2. 앱 내려받기

전자칠판에서 Chrome을 열고(홈 화면에 없으면 `More Apps` 안에 있습니다) 주소창에 입력:

```
github.com/kimju1416/youcall-board-compat/releases/latest
```

`YouCallBoard-compat.apk` 를 눌러 다운로드합니다.

> 💡 USB로 옮겨도 됩니다. PC에서 위 주소로 받아 USB에 담고, 전자칠판의 **File Manager**로 여세요.

## STEP 3. 설치하기

1. 다운로드가 끝나면 알림을 누릅니다 (또는 File Manager ▸ Download 폴더에서 파일을 누름)
2. **「출처를 알 수 없는 앱」** 경고가 뜨면 → `[설정]` ▸ 「이 출처 허용」을 켜고 뒤로 가기
3. `[설치]` ▸ `[열기]`

> ⚠️ 이 경고는 구글 플레이스토어를 거치지 않은 앱이면 무조건 뜹니다. **고장이 아니라 정상입니다.**

## STEP 4. 최초 설정 (앱을 처음 열면 나오는 화면)

| 항목 | 입력 |
|---|---|
| 웹앱 URL | STEP 1에서 복사한 주소 붙여넣기 (입력칸을 길게 눌러 [붙여넣기]) |
| 학년 / 반 | 이 교실의 학년과 반 (예: 3 / 2) |
| 동작 방식 | 아래 STEP 5 참고 |

`[저장하고 시작하기]`를 누르면 끝입니다.

> ⚠️ **「연결 실패」**가 뜨면 주소가 잘못된 것입니다. STEP 1로 돌아가 주소를 다시 확인하세요.

## STEP 5. 동작 방식 두 가지

설정에서 고르고, 나중에 ⚙️ 버튼으로 언제든 바꿀 수 있습니다.

| | **상시 화면형** (기본·추천) | **상주형 (트레이)** |
|---|---|---|
| 평소 화면 | 시간표·급식·학사일정·긴급공지를 항상 표시 | 숨어 있음 (전자칠판을 다른 용도로 사용) |
| 호출이 오면 | 알림 화면으로 전환 | 앱이 자동으로 화면 앞으로 등장 |
| 호출이 끝나면 | 대기화면으로 복귀 | 다시 숨음 |
| 이럴 때 | 전자칠판을 유콜 전용으로 둘 때 | 수업자료·인터넷도 함께 쓸 때 |

> ⚠️ **상주형은 평소 화면이 꺼져 있으므로 긴급공지·학급메모·시간표가 보이지 않습니다.**
> 공지를 학생들에게 계속 보여주려면 상시 화면형을 쓰세요.

## STEP 6. (상주형을 골랐을 때만) 권한 한 번 허용하기

1. 앱을 처음 켜면 **「한 가지 설정이 더 필요합니다」** 창이 뜹니다 ▸ `[설정 열기]`
2. 목록에서 **「유콜 보드」**를 찾아 `[허용]`으로 바꾸고 뒤로 가기

> ⚠️ 이 **'다른 앱 위에 표시'** 권한이 없으면, 다른 화면(수업자료 등)을 보고 있을 때 호출 화면이 뜨지 않고 상단 알림만 표시됩니다.

## STEP 7. 잘 되는지 확인

교무실 PC에서 그 반 학생을 한 명 호출해 보세요. **2~3초 뒤** 교실 화면에 호출이 뜨면 설치 완료입니다.

## 앱 삭제 방법

- 앱 아이콘을 길게 누른 뒤 `[제거]`로 끌어다 놓기
- 또는 **설정 ▸ 애플리케이션 ▸ 유콜 보드 ▸ [제거]**

앱만 지워집니다. 시트·웹앱·다른 교실에는 아무 영향이 없습니다.

## 기능

- 교무실에서 호출하면 학생 이름·번호·메시지·선생님·오시는 곳을 크게 표시
- 호출음 8종 + 음성 안내(TTS), 볼륨·반복 횟수 조절 (화면 오른쪽 위 🔊 버튼)
- 평소엔 오늘/이번주 시간표, 급식(칼로리·알레르기), 학사일정 D-day, 긴급공지, 학급메모 표시
- 화면 꺼짐 방지, 전자칠판 재부팅 시 자동 실행

## 자주 묻는 질문

**앱을 꼭 설치해야 하나요?**
아니요. 지금처럼 브라우저로 접속해서 쓰셔도 모든 기능이 똑같이 동작합니다.

**호출이 2~3초 뒤에 떠요.**
정상입니다. 구글 서버를 거쳐 오는 구조라 2~3초 정도 걸립니다. 앱이든 웹이든 동일합니다.

**교실마다 다르게 써도 되나요?**
됩니다. 1반은 웹, 2반은 앱으로 써도 서로 아무 영향이 없습니다.

**앱을 깔면 교무실 PC도 바꿔야 하나요?**
아니요. 교사용은 지금처럼 웹(주소 뒤 `?role=teacher`) 그대로 쓰시면 됩니다.

**시트를 새로 사본 뜨면?**
주소가 바뀌므로, 앱의 ⚙️ 버튼을 눌러 새 주소로 바꿔주세요.

**전자칠판을 껐다 켜면?**
앱이 자동으로 다시 실행됩니다. 사람이 다시 켤 필요 없습니다.

**소리가 안 나요.**
앱 화면 오른쪽 위 🔊 버튼을 눌러 볼륨과 호출음을 확인하고 `[소리 테스트]`를 눌러보세요.

## 개발

```
npm install
npx cap sync android
cd android && ./gradlew.bat clean assembleRelease
```

빌드하려면 프로젝트 루트에 `youcall-compat.keystore`와 `keystore.properties`가 필요합니다(저장소에 포함되지 않음).
`android/local.properties`도 gitignore라 새 환경에서는 `sdk.dir=C:/Android` 한 줄을 직접 만들어야 합니다.

### 기본판(youcall-board)과의 차이 — 이 세 곳뿐입니다

| 파일 | 변경 |
|---|---|
| `android/variables.gradle` | `minSdkVersion` 24 → **23** (Android 6.0까지) |
| `android/app/build.gradle` | `applicationId`에 `.compat` · `enableV1Signing = true` · v3/v4 서명 끔 |
| `strings.xml` · `capacitor.config.json` | 앱 이름 「유콜 보드 (호환)」 |

화면·기능 코드(`www/`)는 기본판과 **내용이 동일**합니다(줄바꿈 표기만 CRLF/LF로 다름 — 두 APK에서 꺼낸 `app.js`를 `tr -d '\r'` 후 해시 대조해 확인). 기본판이 갱신되면 `www/`만 가져와 다시 빌드하세요.

### Android 6.0 실측 결과

API 23 에뮬레이터(WebView 44)에서 **설치·실행·권한 안내까지 정상 동작**을 확인했습니다.
다만 그 화면은 레이아웃이 무너집니다 — `www/style.css`가 CSS 변수(Chrome 49+) 113곳, CSS Grid(57+) 5곳, flex `gap`(84+) 19곳을 쓰기 때문입니다.
**WebView가 공장 출하 상태인 Android 6.0 기기에서는 앱 대신 브라우저로 유콜 주소를 여는 편이 낫습니다.** Android 7.0 이상은 해당 없습니다.
